# Mine Assist

Minecraft 26.2 (Fabric) 자동 가지굴 채광 모드 — Made by seolwoni

- 바라보는 방향(동서남북)으로 목표 Y까지 계단을 파고 내려가 2x2 가운데 굴 + 1x2 가지굴(3칸 간격) 채광
- 캐기 전에 용암·물을 조약돌로 막고, 바닥 구멍은 메우고, 자갈·모래는 끝까지 캐기
- 벽·바닥·천장에 드러난 광석을 덩어리째 캐기, 원하는 광석 발견 시 알림
- 횃불 자동 설치(10칸) + 석탄·막대기·판자·원목으로 자동 제작(64개 유지)
- 인벤토리가 차면 시작 지점으로 돌아가 여러 상자(최대 10개, 상자별 담을 아이템 지정)에 보관 후 이어서 파기
- 곡괭이 4모드(파괴보호), 자동 밥, 버리기(조약돌 64개 남김), 몹·체력·용암 안전장치, 이어서 파기, HUD

모든 설정은 Mod Menu → Mine Assist에서. 상자는 바라보고 K로 지정.
